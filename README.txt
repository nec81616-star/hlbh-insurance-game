險中求生城市交通大作戰 v7.1｜簡化連擊競賽版

這版刻意降低學生操作負擔：
1. 移除主路／捷徑二選一，車輛依城市道路節點自動導航，學生不控制路線。
2. 移除個人突發事件選項與倒數彈窗，僅保留全班強制險題。
3. 每三起事故進行一次全班強制險題，另兩起只在老師地圖顯示簡短事件，不打斷學生。
4. 行車遊戲得分速域明確顯示於學生端與老師端，非實際法律最低限速、最高速限；以遊戲安全建議速域計算得分。
   交通暢通與天氣晴朗：35～50 km/h；陰天：30～45；雨天：20～35。
   交通壅塞：晴天15～30、陰天15～30、雨天15～30。
5. 每5秒速度位於目前遊戲目標速域內＋3分；連續4次達標時該次改＋13分（原3分＋10分連擊獎勵）。
   一次未達標，連擊歸零，但總積分不會扣除。事故題暫停期間亦不判定。
6. 選擇時速改成 -5 / -1 / +1 / +5，降低手機操作負擔。
7. 連續拜訪由系統帶車前進，每站＋15分，完成整趟額外＋25分；不再有模糊的準時加碼或趕時間獎勵。
8. 學生端直接顯示安全連擊、拜訪進度、即時排名；老師端顯示全班達標人數。
9. 答對全班保險題仍＋30分；事故不扣分。
10. 13秒天氣／路況變化，以及題目期間暫停變化，皆予以保留。
