【遊戲玩法】
1. 老師建立房間並按「邀請學生」生成 QR Code；學生掃碼輸入名字，選汽車／機車與顏色、選職業、隨機抽連續跑點任務、設定時速，按 READY。
2. 老師按「全員發車」。系統依職業產生 3～4 個可抵達的拜訪地點。學生在手機看「下一站、完成進度」，可切換「主要道路／巷弄捷徑」。路線選擇真的影響老師投影上的路口轉向。主要道路較穩定、個人突發事件較少；巷弄捷徑可能較短，但巷弄段移動較慢、臨時事件較多。
3. 車輛抵達下一站：自動完成拜訪並 +18 分；完成整趟任務再額外 +35 分；若在本趟任務時間內達成再 +12 分（全班問答期間不計時），立即接續下一趟跑點（可持續遊玩直到老師結束）。
4. 道路／氣候：每13秒隨機改變其中一項，全班同步；符合任務及環境調整後的隱藏速度區間每5秒+3分，不符合會提示調整車速。學生可隨時按 ±1。
5. 個人突發事件：路況施工、拜訪改期、禮讓行人、塞車等。只要求當事人選擇應對，其餘玩家繼續。未在15秒內選擇會自動採安全方案。
6. 每30秒沒有自然玩家互撞，系統保底生成玩家－NPC事故。前兩起是個人處置、不打斷全班；每逢第3起事故才是全班強制險問答，老師公布答案、講解後按「繼續行車」。題目不重複，答對+30分。題目期間暫停天氣／路況計時。
7. 「結束本局」顯示總積分前三名，另設「任務達人」、「安全駕駛」、「保險知識王」三個成就。

【教學提醒】
- 本遊戲是教學用簡化模擬：隱藏任務速度區間並非現實的合法速限或安全速度建議；實際上路必須依各路段速限、路況、天氣及交通規則行駛。
- 選擇巷弄不代表可以超速；事件選項採守法、安全的交通處置。
- 事故醫療與修繕金額為模擬數字，不代表現行強制險給付額。

【技術】
- 繼續使用既有 Firebase Realtime Database、匿名登入，保留 QR Code 房號流程。
- 老師端持有路線／碰撞／任務進度的判定權，學生端的選擇透過 Firebase 即時同步。
- 需網路連線供 Firebase SDK、QR Code CDN、Firebase 資料庫使用。
- 網頁及 JavaScript 版本號 v7.0；本地資產帶 ?v=700 防止舊快取。
