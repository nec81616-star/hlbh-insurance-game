險中求生城市交通大作戰 v7.2｜超速撞擊防刷分版

修正重點：
1. 動態超速撞擊門檻 = 當前「得分速域」上限 + 10 km/h；必須「超過」才觸發。
   例：晴天暢通得分35–50 km/h，超過60 km/h觸發。
2. 超速者隨機撞上路燈、電線桿或中央分隔島；車子停在現有道路位置並顯示事故動畫與物件標籤。
3. 事故扣 50 分，積分最低為0；安全連擊歸零、暫停行駛4秒、強制把時速降至撞擊門檻。
4. 撞擊為個人事件，不額外啟動全班選擇題，也不計入原有每3起一次的全班事故題循環。
5. 不再讓160 km/h的設定加快拜訪任務刷分：行駛模擬速度至多按照超速門檻計算；危險超速時禁止獲得拜訪獎勵。
6. 路況／天氣每13秒變化後有3秒的調速緩衝，以免瞬間突變即扣分。這3秒內危險超速仍無法領取拜訪獎勵。
7. 學生畫面顯示最新撞擊門檻，事故時顯示原因、扣分、4秒停車提示；停車期間暫時停用調速鍵。
8. 所有得分更新使用Firebase transaction，以降低與其他加分同時發生時的資料覆寫。
9. 保留 v7.1 連擊積分、任務完成獎勵、30秒事故保底、每3起事故一次全班問答等規則。
