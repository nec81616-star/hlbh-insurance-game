強制險城市大冒險｜多人版 v2
============================

這版主要修改
------------
1. 老師投影改成十字道路＋四方向車流。
   - 學生車不再全部從下方出發。
   - 車輛可由上、下、左、右進入。
   - 車輛走出畫面後，會隨機從另一方向重新進場。
   - 另有環境 NPC 車流，投影畫面更像城市道路。

2. 車速整體約提高為上一版的 2 倍。
   - 玩家輸入的時速會直接影響大螢幕移動速度。
   - 車流會無限循環，直到老師按「結束本局」。

3. 每局只安排少數學生發生事故。
   - 1 名學生測試時：與 NPC 車互撞。
   - 全班遊玩時：依風險加權隨機挑選 2～3 名學生，發生一次多人互撞事故。
   - 高時速、情境壓力、分心、低機動性等因素會提高被抽中的權重。
   - 並非真實事故機率，僅為遊戲平衡參數。

4. 事故題改成「全班共同作答」。
   - 事故發生後，全班手機同時跳題。
   - 老師投影會顯示事故雙方／多人資訊。
   - A～D 每個選項都有即時百分比進度條。
   - 老師可按「公布答案」，再按「繼續行車」。

5. 財產系統改為積分制。
   - 取消起始財產排行，避免職業先天金額不同造成不公平。
   - 每 20 秒依駕駛速度給安全積分：
     <=20：+5
     21～30：+8
     31～50：+10
     51～60：+8
     61～80：+4
     >80：+0
   - 發生事故：-50 分。
   - 強制險題答對：+100 分。
   - 老師右側主要顯示即時積分排行。

6. 車輛防護力仍有作用。
   - 事故時會依速度與防護力產生不同的模擬傷害程度。
   - 健康值仍保留在學生端。
