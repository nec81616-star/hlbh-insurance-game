險中求生城市交通大作戰 v6.17

本版更新：

一、路況與天氣動態變化
- 每 13 秒一定改變「路況」或「天氣」其中一項。
- 每次只改一項，不會兩項同時跳動。
- 被抽到的項目一定會換成與目前不同的狀態。
- 路況仍為：暢通 / 壅塞。
- 天氣仍為：晴天 / 陰天 / 雨天。
- 老師端與所有學生端即時同步。
- 學生端環境變更時會短暫提示「路況變化」或「天氣變化」。
- 下一次每 5 秒的任務得分判定，直接採用最新環境修正值。

二、車種選擇簡化
- 移除防護力、機動性、雨天穩定等星等。
- game-data 中也移除這些不再使用的參數。
- 醫療模擬值不再讀取 protection。
- 汽車 / 機車目前只影響地圖外觀、事故敘事與車損敘事差異，不直接影響任務得分。
- 這樣可避免學生誤認為不存在的能力值會影響得分。

三、快取
- 老師首頁更新為 v=617。
- QR 學生網址更新為 v=617。
