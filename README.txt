險中求生城市交通大作戰｜v4

本版重點
1. 老師頁面在線時房間才存在；老師關閉頁面後，Firebase onDisconnect 會移除房間，學生端也會用 heartbeat 檢查並自動踢回登入頁。
2. 舊房號若沒有老師在線，學生無法加入。
3. 地圖改為 4 個主要十字路口＋中央巷道。四個主要路口各自有紅綠燈。
4. 車輛會在道路網路中直行、左轉、右轉，不再從一側跑完後瞬間跳到另一側。到地圖邊緣時會在畫面外迴轉後從同一側自然重新進場。
5. 玩家車與背景車共用車距控制；路口也有進入管制，避免一般行駛時車體重疊。
6. 機車依行進方向採更靠右側／靠路邊的位置，汽車在較內側。
7. 建築物改成學校、咖啡店、辦公大樓、醫院、公園、商店、加油站、住宅等不同樣式。
8. 學生職業卡縮小，只保留圖示、職業名稱與選擇按鈕。
9. 保留 v3 的積分排行、全班事故題、即時投票比例與 1~3 名學生互撞事故。

v5.1：老師頁標題下方新增固定房間控制列；「邀請學生」「成員名單」永遠可見，建立房間後啟用；頁面顯示 v5.1 版本標記以確認 GitHub Pages 已更新。

v5.2：
1. 修正學生被誤判「老師沒開房間」：不再拿手機本機時間與 Firebase ServerValue.TIMESTAMP 做 20 秒差值判斷。
2. 房間是否有效改由 Firebase 房間存在 + hostOnline 判定；老師頁斷線時 onDisconnect 會移除房間。
3. 學生加入頁只顯示鎖定房號與姓名，移除座號。
4. 未帶 ?room=XXXX 的 student.html 不允許自行填房號，要求重新掃描老師邀請 QR Code。
